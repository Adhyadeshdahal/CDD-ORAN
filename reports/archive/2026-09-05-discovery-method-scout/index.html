A survey of scalable label-free conditional-independence tests for the E2/E3/E4 discovery slices, produced during the E2 overnight run. The one decision this raises

The frozen E2 method (|pdCor| + per-candidate 999-permutation null + BH-FDR) is memory-bandwidth-bound: O(N²) distance matrices × 999 permutations × 84 candidates × 10 seeds → ~5–18 days on this box. The scout found that a randomized-Fourier kernel CI test (RCoT/RCIT) would answer the same scientific question (nonlinear conditional dependence, non-monotonic + scale channels) at linear-N with an analytic null — no O(N²), no permutations.

Because no E2 truth has been examined yet, registering a faster method now would still be anti-p-hacking clean (the freeze discipline forbids changing the method after seeing results, not before). So there is a legitimate fork:

  • (A) Complete the frozen pdCor run as-is — preregistered, honest, but slow (days).
  • (B) Register a new scalable protocol (RCoT primary, WGCM cross-check) BEFORE any truth, freeze it, then run — hours not days, same scientific claim.

E4 — latent confounder / wrong sign (label-free)

Honest floor: sign is not identified from association alone — an extra lever is required.

  • Non-Gaussianity → RCD / ParceLiNGAM (arXiv:2001.04197): higher-order moments identify direction and flag confounded pairs → recovers correct sign. The minimal honest move if SCM noise is non-Gaussian.
  • Proxy / negative-control (proximal) (arXiv:1609.08816): recovers sign if the benchmark exposes a proxy of the latent; needs bridge/relevance assumptions.
  • FCI / RFCI: PAG with a bidirected edge detects confounding but gives no sign; only as good as the CI test it uses. Diagnostic, not solution.
  • If a do() intervention is permitted, one interventional sample settles the sign — cheapest.

E3 — temporal / delayed harm

Stay in-frame: PCMCI+ is iterative CI testing with MCI conditioning — same score-matrix + threshold pattern already in use. Minimal compatible move: restrict candidate parents to t-lagged variables, run the existing score on lagged pairs, orient t→t+1 by temporal ordering (free direction, no new framework). Nonlinear Granger / dynotears are heavier reframings — skip unless E3 stalls.

Recommendation (from the scout, opinionated)

  1. Prototype RCoT as a scalable drop-in CI test — single highest-leverage move; keep the BH-FDR layer unchanged.
  2. Weighted-GCM (grad-boosted regressions + squared-residual feature) as a cheap, interpretable, analytic-null cross-check; orthogonal residual view → agreement is a strong label-free confidence signal.
  3. Do NOT bother with: normalizing-flow CI (unproven/heavy), full KCIT (cubic), CDC (keeps O(N²)), and plain unweighted GCM (reproduces Pearson's blind spot to E2's P0² channel).
  4. E4: check whether SCM noise is non-Gaussian first; if so RCD is the minimal sign-recovering addition; otherwise a proxy or intervention is required — say so honestly, don't claim label-free sign identification.
